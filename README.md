## 🚀 Projet phare — EasyCleanESAT

> Application métier développée pour l'**ESAT de Domfront** en méthode **Agile / Scrum**.

**Objectif** : Générer automatiquement des fiches chantier pour les travailleurs en situation de handicap, remplacer les processus papier par un outil numérique adapté.

**Stack** : `Symfony` · `PHP` · `MySQL` · `GitHub` · `Scrum`

✅ Développé en équipe de 4 · Gestion de versions Git · Modélisation du SI · Déploiement en conditions réelles
